# Question Replacement Workflow

After each club session, replace used questions to keep the board fresh for returning members.

## Steps

1. **Screenshot** — Take a screenshot of the board at the end of the session. Dimmed cells = used questions.
2. **Identify** — List the used questions by category and level.
3. **Replace** — Write new questions matching each slot's category theme and difficulty level. Avoid reusing themes from previously rotated-out questions.
4. **Review** — Present replacements for review before editing files.
5. **Update** — Edit both `questions.txt` and `QUESTIONS.md` in sync.
6. **Commit & push** — Commit the changes and push to GitHub.
